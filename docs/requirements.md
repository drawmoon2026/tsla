# 需求文档 v1.0（2026-07-31 整理）

> 来源：用户在 07-23 至 07-31 全部对话中表达的诉求，逐条重构。
> 每条标注：现状 → 差距 → 可交付方案 → 类别（🔧 工程可交付 / ⚖️ 受市场现实约束需管理预期）。

## R1 每日决策服务（核心诉求）

**用户原话线索**："什么时候买什么时候卖"、"仓位 30% 还可以买多少"、"走一步看十步"、"不要等发生了再决定"

- 现状：今日合议卡有立场但措辞保守（"系统今日无正式建议"）；棋谱有预案树但个人参数空缺
- 差距：从"研究员的谨慎"到"作战参谋的明确"——用户要的是**三态明确指令**（买 X 股 @什么条件 / 卖 / 等）+ 理由 + 置信度
- 方案 🔧：决策卡升级为指令式输出（基于冻结规则 + 用户批准的个人参数合成）；参数未批准的部分显式要求用户补全
- 依赖：用户填 position.json（真实权益、减仓线、容忍线）

## R2 收益引擎（最大落差所在）

**用户原话线索**："胜率 70% 以上"、"年收益率"、"3 年 2 次无法接受"（频率）

- 现状：唯一冻结候选 E8-A+S2 留出段 83.3% 胜率 / 年化 ≈+14.6%（5.4 笔/月）——数字达标但样本不显著、且当前 S2 停用区发不出信号（回撤 -36%）
- 差距（诚实拆解）：
  - ⚖️ **市场现实部分**：TSLA 单标的日内的"胜率×期望"前沿已被 ~3400 组合探明——70% 胜率 + 高期望同时成立的空间极窄，这不是工程能改变的
  - 🔧 **工程可扩展部分（最大的未挖掘机会）**：**E8 已证明模型跨标的迁移成立（26/26 只股票 AUC>0.55）**——把观察池从 TSLA 一只扩展到 26 只，信号频率理论上 ×10 以上、单标的 regime 风险被分散（TSLA 在停用区时其他标的照常出信号）、组合层年化有实质提升空间。这是缩小收益差距的第一杠杆
- 方案 🔧：多标的池 shadow 上线（复用冻结模型，每标的独立 S2 开关）；组合层回测先行验证

## R3 情报线（哨兵/因果探测器）

**用户原话线索**："第一时间知道"、"找到线索源头跟着买"、"情报分析+股市数据预测走势"

- 现状：13 渠道 24h 采集、探测器标定中（08-20 出闸）、四维评分 v0；**情报还没有喂进决策**——采集与决策两张皮
- 方案 🔧：a) LLM 晨间情报解读（每天对新 T0/T1 事件做语义摘要 + 影响判断，前向积累防污染）；b) 情报状态直接进决策卡合成逻辑；c) 意外分实现（用期权 IV 做共识基线）

## R4 推演系统

- 现状：双模式回放 + 每日续演 + 棋谱预案（用户历次反馈已修：频率误解/旧算法/买卖记录/总结卡）
- 剩余差距 🔧：**假设推演**（what-if 沙盘：改个人参数立即看历史推演结果变化）——受控范围仅个人参数，冻结规则不动

## R5 自动化交付形态（"交付"的定义）

- 现状：shadow（只记账不下单）
- 交付阶梯：shadow → **paper（Alpaca 纸上真实下单，验证全链路）** → 小仓位真钱
- 方案 🔧：AlpacaBroker 实装（架构接口壳已在，实装约数天）；通知推送（信号触发时手机能收到，不用盯页面）

## R6 产品体验

- 已定版：墨金配色、三页面、返回导航
- 剩余 🔧：手机可看（局域网服务）、信号推送通知

## 修订 v1.1（2026-08-01，用户澄清后重定向）

**用户定调**："能全面模拟，我要的是算法、数据挖掘，跟真钱没有关系，模拟就行。"

- **交付物重定义**：一台全面模拟 + 算法实验 + 数据挖掘的研究机器。R5（paper/真钱执行）**整体出局**，AlpacaBroker 实装取消。
- 新的优先级：
  1. **全面模拟**：多标的池组合级模拟（26 标的 × 冻结模型 × 各自 S2 开关 × 组合资金账本）——E14 实验
  2. **what-if 沙盘**：推演页可改参数即时看历史推演结果变化（个人参数 + 受控策略参数）
  3. **数据挖掘持续**：实验室 E/N 系列照常运转，池级数据资产（26 标的价格/空头/坑目录）已就位
- 时间表修订：M1（~08-07）= 多标的组合模拟 + what-if 沙盘；M2（~08-25）= 探测器出闸 + LLM 情报解读 + 挖掘第二轮；M3 = 前向裁决报告（纯研究结论，不涉真钱）
